Alpha Forge Workbook Audit

The app matches the workbook's tab names and general navigation, but it does not yet behave like one workbook-driven model. The highest-risk gap is broken dependency ownership: assumptions, revenue, projections, WACC, and DCF are split across separate local frontend models instead of one shared lineage.

Broad Verdict

UI structure is workbook-like. Model structure is not yet workbook-faithful.

Strongest Areas

WACC layout, relative valuation structure, and final valuation weighting are closest to workbook intent.

Highest-Risk Areas

Global assumptions, segment revenue rollup, projections-to-DCF dependency, and D&A sequence handling.

Major Findings

Critical

No Shared Assumptions Model

The workbook expects one assumptions layer. Alpha Forge splits tax, risk-free rate, and MRP across WACC local state, Projections local state, DCF constants, and backend defaults.

Critical

Revenue Is Not Segment-First

The workbook rolls total revenue from segment rows. Alpha Forge exposes only total revenue and a single growth vector.

Critical

Projections Do Not Feed DCF

Revenue and Projections edits stay inside their own tabs. DCF builds a separate forecast tree and ignores those edits.

Critical

D&A Sequence Deviates

Projected operating profit excludes D&A as a deduction even though D&A is also added back later, which breaks workbook-like EBIT and NOPAT lineage.

Moderate

WACC Share Sourcing Is Inconsistent

WACC leaves diluted shares blank when fixture data is missing, while DCF falls back to market cap divided by price.

Moderate

Backend Is Not The Canonical Model Backbone

The backend payload is still a thin historical snapshot plus a simple standalone DCF, not a unified workbook-style model graph.

Canonical vs Observed Flow

Canonical Workbook Flow

Introduction / seed values → Assumptions → Revenue (segment-first) → Projections → WACC → Relative Valuation → DCF → Final Valuation

Observed Alpha Forge Flow

Backend payload → CompanyPage tab shell → Assumptions display only → Revenue local model → Projections local model → WACC local model (shared upward) → Relative Valuation local model (shared upward) → DCF local model (shared upward) → Final Valuation weighting

What To Inspect Next

  1. Define one shared assumptions owner and confirm propagation into WACC, Projections, and DCF.
  2. Decide which model owns projected revenue and statement rows, then remove parallel forecast trees.
  3. Add a segment-first revenue schema and total-revenue rollup contract.
  4. Reconcile D&A, EBIT, EBITDA, and NOPAT sequence with the workbook.
  5. Normalize share-count sourcing across WACC, relative valuation, and DCF.
